## Before publishing
1. Put your real `resume.pdf` in this folder.
2. Replace the placeholder GitHub URL with your actual GitHub profile.
3. Replace each project `#` link with the real repository/demo.
4. To use your photo, replace the `SS` avatar in index.html with an image element such as `<img src="profile.jpg" alt="Shivraj Singh">` and add `profile.jpg`.

## GitHub Pages
Create a repository, upload these files, then Settings → Pages → Deploy from branch → main → /root.
